== 0.1.1 (29 avril 2026)

=== Modifié

* **Repo GitHub renommé** vers `aloli-crystal/antora` (convention de
  nommage Aloli : les créations originales abandonnent le préfixe
  `crystal-`). Les anciens liens redirigent automatiquement.
* Champ `name:`, cible de compilation et binaire CLI alignés sur le
  nouveau nom du repo. Fichier d'entrée renommé `src/crystal_antora.cr`
  → `src/antora.cr`. La cible `main:` pointe désormais sur la source
  `src/antora.cr` (auparavant pointée sur `bin/crystal-antora`, le
  binaire compilé).
* Le module interne `CrystalAntora` et le dossier
  `src/crystal_antora/` restent inchangés — nettoyage reporté.
