Toutes les modifications notables de ce projet sont documentées dans ce fichier.

Le format s'inspire de https://keepachangelog.com/fr/1.1.0/[Keep a Changelog]
et ce projet suit https://semver.org/lang/fr/[Semantic Versioning].

== 0.1.5 (28 juillet 2026)

=== Modifié

* **Dépendances renommées** (abandon du préfixe `crystal-` dans l'org `aloli-crystal`) :
  `crystal-asciidoctor` → `asciicrystal` (`~> 2.0.26.12`), `crystal-rouge` → `rouge`
  (`~> 4.7.0.3`), `crystal-saml` → `saml`. Le `require "crystal-saml"` devient `require "saml"`.
  La mention « communauté Asciidoctor » (projet upstream) est conservée.

== 0.1.2 (29 avril 2026)

=== Modifié

* **Module interne renommé** `CrystalAntora` → `Antora` (convention
  Aloli).
* Dossier source `src/crystal_antora/` → `src/antora/`. Chemins
  `require` internes adaptés.
* Comportement et surface CLI inchangés.

=== Note pour les consommateurs

Aucun consommateur externe ne référence `CrystalAntora::*` aujourd'hui ;
renommage purement interne.

== 0.1.1 (29 avril 2026)

=== Modifié

* **Repo GitHub renommé** vers `aloli-crystal/antora` (convention de
  nommage Aloli : les créations originales abandonnent le préfixe
  `crystal-`). Les anciens liens redirigent automatiquement.
* Champ `name:`, cible de compilation et binaire CLI alignés sur le
  nouveau nom du repo. Fichier d'entrée renommé `src/crystal_antora.cr`
  → `src/antora.cr`. La cible `main:` pointe désormais sur la source
  `src/antora.cr` (auparavant pointée sur `bin/crystal-antora`, le
  binaire compilé).
* Le module interne `CrystalAntora` et le dossier
  `src/crystal_antora/` restent inchangés — nettoyage reporté.
